### Overview
In the Pañhabyākaraṇa Sutta the Buddha says that there are four ways of answering questions (*cattārimāni pañhabyākaraṇāni*, A-iv 465:1): a question to be answered categorically, analytically, with a counter-question, or to be set aside. The sutta closes with the verse "One is a categorical statement, another an analytical statement; the third one should counter-question, but the fourth should be set aside" (A-iv 466:1-467:1). The commentaries on the parallel passage in the Saṅgīti Sutta (Sv-ii 622:1-12) and the Aṅguttara commentary (Mp-iii 727:4-14) give an example for each, using the impermanence of the eye.

### The List
1. **Ekaṃsabyākaraṇīya** - To be answered categorically: a question that is to be answered with one definite answer (*ekaṃseneva byākātabbo*, Sv-pt-ii 572:1). Example: asked "Is the eye impermanent?", one answers directly, "Yes, impermanent" (Sv-ii 622:2-5).
2. **Vibhajjabyākaraṇīya** - To be answered analytically: a question that is to be answered after dividing the matter asked (*vibhajja*, Sv-pt-ii 572:2). Example: asked "Is the eye called impermanent?", one divides: "Not the eye alone, the ear and the nose are impermanent too" (Sv-ii 622:6-8).
3. **Paṭipucchābyākaraṇīya** - To be answered with a counter-question: the questioner is asked a question first (Sv-pt-ii 572:3). Example: asked "As the eye is, so is the ear; as the ear is, so is the eye", one asks "In what sense do you ask?" If he says "in the sense of seeing", one answers "No"; if "in the sense of impermanence", one answers "Yes" (Sv-ii 622:9-10).
4. **Ṭhapanīya** - To be set aside: a question that is not to be answered, because it cannot be answered in any of the three ways (Sv-pt-ii 572:4). Example: "Is the soul the same as the body?", about which one says "This has not been declared by the Blessed One" (Sv-ii 622:11-12).


### Quote
> **“Cattārimāni, bhikkhave, pañhabyākaraṇāni. Katamāni cattāri? Atthi, bhikkhave, pañho ekaṃsabyākaraṇīyo; atthi, bhikkhave, pañho vibhajjabyākaraṇīyo; atthi, bhikkhave, pañho paṭipucchābyākaraṇīyo; atthi, bhikkhave, pañho ṭhapanīyo. “Ekaṃsavacanaṃ ekaṃ, vibhajjavacanāparaṃ; Tatiyaṃ paṭipuccheyya, catutthaṃ pana ṭhāpaye.**  
> “Monks, there are these four ways of answering questions. What are the four? There is, monks, a question to be answered categorically; there is, monks, a question to be answered analytically; there is, monks, a question to be answered with a counter-question; there is, monks, a question to be set aside. “One is a categorical statement, another an analytical statement; the third one should counter-question, but the fourth one should be set aside.  
>
